HOW TO USE
----------
1. Keep index.html, style.css and script.js in the same folder.
2. Put your resume PDF in this folder and name it exactly: resume.pdf
3. Double-click index.html to open the portfolio in Chrome.
4. Edit the project links in index.html where you see "Add Live Demo" or "Add GitHub Link".
5. If you want to change text, edit index.html.
6. If you want to change colors/design, edit style.css.
